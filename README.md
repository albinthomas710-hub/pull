# Pull

A weekly instrument for people starting a company.

Pull does not brainstorm ideas, score a pitch, or interview customers for you. It keeps the only loop that early founders actually skip:

1. Name ten people you can reach.
2. Ask what they did last time. Do not pitch.
3. Wait until three of them describe the same pain.
4. Get a commitment: a date, an intro, their data, or money.
5. Do the job by hand.
6. Count one number every week.
7. Write an application only from that log.

Anything you cannot point at stays blank.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3001

MIT licensed. The log never leaves the browser.

Your log stays in this browser. Export it before you clear the site data.

## What it will not do

- Invent traction
- Count a pitched conversation as demand
- Tell you to build before three people share a pain and someone commits
- Replace talking to a human

The worked example is a freight-broker log. Load it to see a true week, then erase it and start with your own names.
